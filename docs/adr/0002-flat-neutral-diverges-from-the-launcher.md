# Flat-neutral, not the launcher palette

The desktop launcher and the project site use a dark violet palette with a
blue-to-magenta show gradient. The onboarding view uses neutral greys with a
single system-blue accent instead, and no gradient at all.

The setup screen is the first thing a player sees, on a television, with a
controller, before any game branding has loaded. It reads as part of the console
rather than part of the show: flat surfaces, one focus ring, semantic green and
red, large type. Carrying the show gradient onto it made the page look like a
title screen that had not finished loading.

This also frees the design from the site's colours, which are not ours to keep
in step. The page has to stay legible at 720p over a controller-driven focus
ring, and neutral greys are the cheapest way to guarantee contrast in both
flavors.
